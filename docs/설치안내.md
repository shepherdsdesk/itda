# 잇다 설치 안내

> 그림이 있는 설명서: **https://mokyangdesk.com/itda-install.html**

잇다 앱 주소 **https://shepherdsdesk.github.io/itda/** 는 모든 교구가 함께 씁니다.
교구마다 다른 것은 **구글 시트 사본** 하나뿐이고, 명단과 보고는 그 시트에만 저장됩니다.

## 1. 사본 만들기
소개 페이지(mokyangdesk.com/itda.html)의 **내 드라이브에 사본 만들기** → 문서 복사 화면에서 **사본 만들기**.
프로그램 코드(Apps Script)도 함께 복사됩니다. 교회·교구 공용 구글 계정을 권합니다.

## 2. 처음 설정
시트를 새로고침 → 메뉴 **잇다 → ① 처음 설정** → 권한 허용(고급 → 이동 → 계속 → **모두 선택** → 계속) → ① 을 한 번 더.

## 3. 체험판 둘러보기 · 사용키 넣기
처음 설정이 끝나면 **체험교구**(관리자 `admin` — 접속코드는 안내 창과 [사용자] 탭에, 열두 제자·사랑방 3곳)가 생깁니다.
4·5단계로 배포한 뒤 admin으로 둘러보세요. 실제 명단 올리기는 사용키를 넣은 뒤 열립니다.
- 사용 요청: https://mokyangdesk.com/itda.html#request
- 받은 키: [설정] 교회이름을 요청 때와 똑같이 → 메뉴 **잇다 → ③ 사용키 넣기**
- 실제 시작 전: 메뉴 **⑤ 체험 데이터 지우기**

### 내 계정 넣기
[사용자] 시트 첫 줄: 이름 · 역할 `관리자` · 교구 `5교구`.
- 교구 칸에 교구를 적으면 그 교구만 보는 **교구 관리자**
- 교구 칸을 비우면 시트 안의 모든 교구를 고르는 **교회 전체 관리자**

## 4. 웹 앱으로 배포
확장 프로그램 → Apps Script → **배포 → 새 배포 → ⚙ 웹 앱**
- 실행: **나** · 액세스: **모든 사용자** → 배포 → 액세스 승인 → 웹 앱 URL **복사**

## 5. 내 링크로 들어가기
시트 메뉴 **잇다 → ② 접속코드·개인 링크 만들기** → 웹 앱 URL 붙여 넣기 → 안내 창의 내 링크를 휴대폰으로 열기 → 홈 화면에 추가.

## 6. 교구 명단 올리기
앱 **명단 관리 → 파일 선택** → 교회 시스템 명단(xls·xlsx·csv) 그대로 → 미리 보기 확인 → **추가·갱신 → 반영**.

| 교회 명단 칸 | 잇다에서 |
|---|---|
| 소속(주요항목) `5교구 / 이매 / 이매12` | 교구 · 마을 **이매** · 사랑방 **이매12** |
| 그룹직책 `사랑방장` | ★ 사랑방장 (보고 링크 생성) |
| 그룹직책 `목회자` · 교회직분 `교구목사` | 교구 목회자 |
| 이름 · 핸드폰 · 교회직분 | 이름 · 연락처 · 직분 |

## 7. 사랑방장에게 링크 보내기
명단 관리 → 🔗 사랑방장 링크 → **전체 복사** → 사랑방장 단톡방에 붙여 넣기. (마을을 고르면 그 마을 링크만)
- 갤럭시: 「설치」 한 번 · 아이폰: 공유 → 홈 화면에 추가 → 추가

## 새 버전으로 바꾸기
GitHub `gas/Code.gs` 를 Apps Script에 덮어 붙이고 저장 → **배포 → 배포 관리 → ✏ 수정 → 새 버전 → 배포**.
⚠️ 「새 배포」를 누르면 서버 주소가 바뀌어 이미 보낸 링크가 모두 작동하지 않습니다.
