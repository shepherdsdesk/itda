# 잇다 (it,da) — 사랑방과 목자를 잇는 주일보고

사랑방장이 주일 출석·기도제목·부탁(📞심방전화 · 🙏기도부탁 · 🏠심방부탁)을 올리면, 교구 목회자가 바로 확인하고 코멘트·확인·전화·상황별 문자로 응답합니다.
**구글 시트(저장) + 앱스크립트(서버) + GitHub Pages(휴대폰 앱 화면)** 로 동작합니다.

```
sarangbang-report/
├─ gas/Code.gs            ← 구글 앱스크립트에 붙여 넣을 서버 코드
├─ app/                   ← GitHub Pages에 올릴 앱 (홈 화면 설치용)
└─ 잇다_명단양식.csv       ← 명단을 직접 만들 때 쓰는 빈 양식
```

> **먼저 체험해 보기**: `app/index.html`을 그대로 열면 체험 모드입니다.
> 사랑방장 `홍길동 / 1111` · 목회자 `이세진 / 0000` · 관리자 `관리자 / 9999`

---

## 누가 무엇을 정하나요? (배정 구조)

| 역할 | 하는 일 | 어디서 |
|---|---|---|
| **관리자** (목사님 본인 또는 교회 행정) | 교구 목회자를 교구에 배정하고 링크를 보냄 | 앱 → **교역자** 탭 |
| **교구 목회자** | 자기 교구 명단 올리기 → 사랑방 편성 → ★ 사랑방장 지정 → 링크 보내기 | 앱 → **명단 관리** 탭 |
| **사랑방장** | 받은 링크를 눌러 매주 보고만 함 (설정할 것 없음) | 앱 → 보고 화면 |

교구 목사님마다 자기 교구만 보이고, 사랑방장마다 자기 사랑방만 보입니다. 한 사랑방에 사랑방장을 두 명(부부 등) 지정해도 됩니다.

## 성도 명단 올리기 — 교회 시스템 파일 그대로

교회 시스템에서 내려받은 **엑셀(xlsx)·CSV**를 손대지 않고 그대로 올리면 됩니다. (맨 위 제목 줄, 한글 CSV 모두 인식)

| 교회 시스템 칸 | 잇다에서 쓰는 방법 |
|---|---|
| **소속(주요항목)** | `교구 / 지역 / 사랑방` 순서로 읽음 — `5교구 / 아름 / 아름12` → 5교구 **아름12**, `5교구 / 여수11` → **여수11**, `5교구 / 2025청장년 / 에스라` → **에스라**. `5교구`만 있으면 교구 소속(목회자 등) |
| **그룹직책 · 교회직분** | 그룹직책 `사랑방장` → ★ 사랑방장 (보고 링크 생성) · 그룹직책 `목회자` 또는 교회직분 `교구목사`(목사·전도사) → 그 교구 목회자 계정 · 나머지 → 사랑방원 |
| **이름 · 교회직분** | 이름 · 직분 (집사·권사 등) |
| **핸드폰** | 연락처 (전화번호보다 핸드폰을 먼저 사용, `1012345678`처럼 0이 빠져도 자동 보정) |
| 나머지 칸 | 쓰지 않음 (생년월일·주소 등은 저장하지 않습니다) |

**관리자(교회 전체 파일)** — 명단 관리 → 파일 선택 → **‘교회 전체 파일 — 모든 교구 한 번에 반영’**을 켜면, 소속 칸의 교구별로 나눠 넣고 **교구목사와 사랑방장이 한 번에 배정**됩니다. 그다음 교역자 탭에서 교구목사님들께 링크를 보내면 끝.

**교구 목회자(내 교구 파일)** — 같은 파일을 올리면 내 교구 사람만 반영되고 다른 교구는 자동으로 빠집니다.

반영 방법은 평소엔 **추가·갱신**, 새 학기 사랑방 재편성 땐 **교구 명단 전체 바꾸기**(지난 보고 기록은 그대로). 반영 후에도 명단에서 이름을 눌러 사랑방 이동·★ 사랑방장 지정/해제·삭제를 할 수 있고, 사랑방장을 지정하면 바로 카톡으로 링크를 보낼 수 있습니다.

새가족은 사랑방장이 보고할 때 이름만 넣으면 다음 주부터 그 사랑방 명단에 자동으로 들어갑니다.

## 홈 화면 설치는 얼마나 번거롭나요?

- 사랑방장은 **카톡으로 받은 링크를 한 번 누르는 것**이 전부입니다. 로그인도 필요 없습니다.
- 카톡 안에서 열려도 Chrome/Safari로 **자동으로 다시 열립니다**.
- **갤럭시**: "설치할까요?" 창에서 **설치** 한 번이면 끝입니다.
- **아이폰**: 애플이 웹 앱의 자동 설치를 막아 두어서, 처음 한 번만 **공유 → 홈 화면에 추가 → 추가** 3번 눌러야 합니다. 화면에 그림 안내가 뜹니다. 로그인 상태 그대로 설치됩니다.
- 설치를 안 해도 쓸 수 있습니다. 카톡의 그 링크를 누를 때마다 바로 보고 화면이 열립니다.
- 💡 사랑방장 모임 때 5분만 함께 설치해 드리면 가장 확실합니다.

## 처음 한 번 설치 (목사님이 하실 일)

### 1. 구글 시트 + 서버
1. 구글 드라이브에서 **새 구글 시트**를 만들고 이름을 `잇다`로 바꿉니다.
2. **확장 프로그램 → Apps Script**를 엽니다. 원래 코드를 지우고 `gas/Code.gs`를 붙여 넣은 뒤 저장합니다.
3. 함수 **`setup`** 을 실행하고 권한을 허용합니다. 시트 탭들이 만들어집니다.
4. **사용자** 시트에 **본인을 `관리자`** 로 한 줄 넣습니다. 이름과 교구만 넣으면 됩니다. 예시 줄은 지워도 됩니다.
5. 시트 메뉴 **잇다 → ② 접속코드·개인 링크 만들기**를 누릅니다. 본인 접속코드가 생깁니다.
6. **배포 → 새 배포 → 웹 앱**을 고릅니다. 실행은 **나**, 액세스는 **모든 사용자**로 하고 배포합니다. 나오는 **웹 앱 URL**을 복사합니다.

### 2. 앱 올리기 (GitHub Pages)
1. `app/index.html` 맨 위 `const API_URL = '';` 따옴표 안에 웹 앱 URL을 넣습니다.
2. GitHub(shepherdsdesk)에 새 저장소(예: `itda`)를 만들고 `app` 폴더 **안의 파일**을 올립니다.
3. **Settings → Pages → main / (root) → Save**를 누르면 `https://shepherdsdesk.github.io/itda/` 주소가 생깁니다.
4. 시트 **설정** 탭 `앱주소`에 이 주소를 넣습니다.

### 3. 시작
1. 앱에 관리자로 로그인합니다. 시트 **사용자** 탭의 본인 `개인링크`를 쓰면 바로 들어갑니다.
2. **교역자** 탭에서 교구 목사님들을 배정하고 **링크 공유**를 누릅니다.
3. 각 교구 목사님은 **명단 관리**에서 엑셀을 올리고 사랑방장에게 링크를 보냅니다.

## 상황별 문자 · 쉐퍼드 데스크 자료
목회자 화면의 ✉️ 문자는 기도제목 내용을 보고 상황(위로·수술·출산·환우·이사·개업·시험·진로·새가족·생일·안부·기도)을 고릅니다. 받는 분 이름과 직분을 넣은 문안을 만들고, **말씀 넣기 / 문자예화 첨부**를 켜고 끌 수 있습니다.
**문자자료** 시트에 `상황 | 제목 | 본문 | 말씀 | 예화`로 쉐퍼드 데스크 자료를 붙여 넣으면 📁 표시로 기본 문안보다 먼저 나옵니다. `{이름}` 자리에는 받는 분 이름이 들어갑니다.

## 알아 두실 점
- **코드를 고친 뒤**에는 Apps Script에서 **배포 → 배포 관리 → ✏️ → 새 버전 → 배포**를 해야 반영됩니다. 주소는 그대로입니다.
- 개인 링크는 비밀번호와 같습니다. 휴대폰 교체나 링크 유출 때는 명단 관리에서 사랑방장 이름을 누르고 **🔄 링크 새로 만들기**를 누르면 예전 링크가 막힙니다.
- 모든 정보는 목사님 구글 드라이브의 시트에만 저장됩니다.
