특징

교회 명단 그대로, 교구마다 따로

할렐루야교회 5교구에서 먼저 쓰고 있습니다. 교회 이름이나 교구 이름이 박혀 있지 않아 어느 교회, 어느 교구에서든 그대로 가져다 쓰실 수 있습니다.

명단 파일 그대로

교회 시스템에서 내려받은 엑셀을 그대로 올리면 마을·사랑방이 나뉘고, 사랑방장·교구목사가 자동으로 배정됩니다.

홈 화면에 앱처럼

앱 마켓 없이 링크 하나로 갤럭시·아이폰 홈 화면에 설치됩니다. 카톡에서 열어도 자동으로 브라우저로 넘어갑니다.

교구가 관리하는 계정에만

교구마다 자기 구글 시트를 쓰고, 사랑방장은 자기 사랑방만, 목회자는 자기 교구만 봅니다.

상황별 문자

위로·수술·출산·이사·개업·시험 문안에 개역개정 말씀과 짧은 문자예화를 붙여 바로 보냅니다.

돌봄으로 이어지는 기능

숫자에서 사람으로

출석 숫자를 모으는 데서 그치지 않고, 놓치기 쉬운 한 사람을 목회자 앞에 다시 데려다 놓습니다.

연간 현황

최근 1년 주일예배 추이, 마을별·사랑방별 평균, 새가족 수, 보고 제출률을 한 화면에서 봅니다.

장기 결석 알림

3주 이상 연속으로 예배에 빠진 성도를 따로 모아 보여 주고, 바로 전화하거나 안부 문자를 보냅니다.

부탁 처리 기록

확인 뒤 전화함·심방함·기도함을 남깁니다. 기록을 복사해 분기 심방 보고서에 그대로 붙입니다.

주일 저녁 미제출 알림

정한 시각에 보고를 내지 않은 사랑방과 사랑방장 연락처를 목회자 메일로 보냅니다.

지난주처럼

사랑방장은 지난주 출석을 한 번에 불러온 뒤 바뀐 분만 고치면 됩니다.

큰 글씨 보기

어르신 사랑방장도 편하게 쓰시도록 버튼 하나로 글자를 키웁니다.

시작하기 · 공개 배포

앱 주소는 하나,
시트는 교구마다

잇다 앱은 모두 같은 주소를 씁니다. 교구 목회자는 구글 시트 사본만 내 드라이브로 가져와 배포하면, 우리 교구만의 주일보고 서버가 생깁니다. 사랑방장에게 보내는 링크가 그 서버로 자동 연결해 줍니다.

내 드라이브에 사본 만들기 설치 설명서
  1. 1
    사본 만들기버튼을 눌러 구글 시트 사본을 내 드라이브에 만들고, 잇다 → ① 처음 설정을 누릅니다.
  2. 2
    웹 앱으로 배포하기확장 프로그램 → Apps Script에서 ‘배포’를 눌러 우리 교구 서버 주소를 받습니다.
  3. 3
    사용 요청 → 사용키 넣기체험해 보신 뒤 사용 요청을 보내 주시면 사용키를 보내 드립니다. 키를 넣고 교구 명단을 올리면 시작입니다.
체험은 바로사본을 만들면 체험교구·열두 제자 예시 명단으로 모든 화면을 둘러볼 수 있습니다.
구글 계정 하나교회나 교구 공용 계정을 권합니다. 사역자가 바뀌어도 기록이 남습니다.
사용은 허락 후우리 교구 실제 명단은 사용 요청 후 받은 사용키를 넣으면 쓸 수 있습니다.
사용 요청

사용을 요청해 주세요

잇다는 AI목양지원센터의 사용 허락을 받아 쓰는 프로그램입니다. 사용 요청을 보내 주시면 교회이름에 맞춘 7일 체험판 사용키를 보내 드리고, 함께 쓰실 수 있도록 도와 드립니다.

1

체험판으로 둘러보기

사본을 만들면 admin 관리자 계정이 생깁니다. 접속코드는 사본마다 다르게 만들어지고, 시트 메뉴에서 언제든 새로 바꿀 수 있습니다. 열두 제자가 세 사랑방에 나뉘어 있습니다.

2

사용 요청 보내기

교회이름(교구), 담당 목회자, 연락처, 사랑방 수를 적어 보내 주세요. 교회이름에 맞춘 7일 체험판 사용키를 보내 드리고, 계속 쓰시면 정식 사용키를 드립니다.

3

사용키 넣고 시작

시트 메뉴 잇다 → ③ 사용키 넣기(또는 앱 관리자 메뉴)에 넣고, 체험 데이터를 지운 뒤 우리 교구 명단을 올리면 됩니다.
