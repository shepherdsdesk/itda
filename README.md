# 잇다 · it,da

**사랑방과 목자를 잇는 주일보고**

사랑방장은 주일 출석과 기도제목을 휴대폰으로 올리고, 교구 목회자는 바로 확인해 코멘트·전화·문자로 응답합니다.
홈 화면에 앱처럼 설치해 쓰는 웹앱입니다.

## 무엇을 하나요?

### 사랑방장
- 주일 날짜 자동 선택 → 이름 옆 **예배 · 사랑방** 버튼으로 출석 체크
- 새가족·방문자 추가 (다음 주부터 사랑방 명단에 자동 등록)
- 기도제목마다 목회자에게 **📞 심방전화 · 🙏 기도부탁 · 🏠 심방부탁**
- 목회자가 남긴 **💬 코멘트**와 **✓ 확인** 표시를 바로 확인
- 작성 중인 내용은 휴대폰에 자동 보관

### 교구 목회자
- 사랑방별 제출 현황, 주일예배·사랑방 출석 합계, 최근 8주 추이
- 사랑방에서 온 부탁마다 **확인했어요 · 📞 전화 · ✉️ 문자**
- 사랑방 보고에 **코멘트** 남기기 (사랑방장 화면에 표시)
- **상황별 문자** — 위로·수술·출산·환우·이사·개업·시험·진로·새가족·생일·안부·기도 문안에 말씀·문자예화 첨부
- 미제출 사랑방장 안내 문구, 담임목사님·단톡방용 **교구 주일 보고 복사**
- **명단 관리** — 교회 시스템 명단(.xls·.xlsx·.csv)을 그대로 올려 사랑방 편성, ★ 사랑방장 지정, 링크 보내기

### 관리자
- **교역자** 탭에서 교구 목회자 배정, 링크 공유
- 교회 전체 명단 파일 한 번에 반영 — 교구목사·사랑방장 자동 배정

## 교회 시스템 명단 파일 그대로 올리기

| 교회 시스템 칸 | 잇다에서 |
|---|---|
| 소속(주요항목) | `5교구 / 아름 / 아름12` → 5교구 **아름12** 사랑방 (맨 끝이 사랑방) |
| 그룹직책 | `사랑방장` → ★ 사랑방장 · `목회자` → 교구 목회자 · 나머지 → 사랑방원 |
| 교회직분 | 직분 (`교구목사`이면 교구 목회자) |
| 핸드폰 | 연락처 |

생년월일·주소 등 나머지 칸은 저장하지 않습니다.

## 홈 화면 설치

| 기기 | 방법 |
|---|---|

## 구성

```
itda/
├─ index.html             앱 화면 (사랑방장·목회자·관리자)
├─ manifest.webmanifest   홈 화면 설치 정보
├─ sw.js                  앱 화면 빠르게 열기 (보고 데이터는 저장하지 않음)
├─ icons/                 앱 아이콘
├─ gas/Code.gs            서버 코드 — 구글 앱스크립트에 붙여 넣기
├─ docs/설치안내.md        처음 설치하는 방법
└─ docs/잇다_명단양식.csv  명단을 직접 만들 때 쓰는 빈 양식
```

- **저장소:** 구글 시트 (설정 · 사용자 · 성도명단 · 주일보고 · 기도제목 · 목회자응답 · 문자자료)
- **서버:** Google Apps Script 웹 앱
- **앱 화면:** GitHub Pages (이 저장소)

## 처음 설치

자세한 순서는 **[docs/설치안내.md](docs/설치안내.md)** 를 보세요.

1. 새 구글 시트 → 확장 프로그램 → Apps Script → `gas/Code.gs` 붙여 넣기 → `setup` 실행
2. [사용자] 시트에 관리자 한 줄 → 메뉴 **잇다 → ②**
3. 배포 → 새 배포 → 웹 앱 (실행: 나 · 액세스: 모든 사용자) → URL 복사
4. `index.html`의 `const API_URL = '…'`에 URL 넣기 → 이 저장소에 올리고 GitHub Pages 켜기
5. [설정] 시트 `앱주소`에 `https://shepherdsdesk.github.io/itda/` → 메뉴 **잇다 → ②** → 개인 링크로 접속

> 서버 코드를 고친 뒤에는 Apps Script **배포 → 배포 관리 → ✏️ → 새 버전**으로 다시 배포해야 반영됩니다. (주소는 그대로)
